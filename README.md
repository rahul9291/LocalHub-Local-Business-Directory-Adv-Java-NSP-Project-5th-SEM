

\# LocalHub – Local Business Directory Portal



LocalHub is a web-based application that helps users discover local businesses. Business owners can register and list their businesses, while administrators can approve or reject listings.



\## Features

\- User registration and login

\- Browse and search local businesses

\- Category-wise business filtering

\- Business owner dashboard

\- Add, edit and delete business listings

\- Admin dashboard

\- Approve or reject business listings

\- Role-based access



\## Technologies Used

\- HTML

\- CSS

\- Java

\- Java Servlets

\- JDBC

\- MySQL

\- Apache Tomcat



\## Database

Database name: `local\_business\_directory`



Tables:

\- users

\- categories

\- businesses



\## Setup

1\. Install JDK, Apache Tomcat and MySQL.

2\. Create the database `local\_business\_directory`.

3\. Import or create the required tables.

4\. Set the environment variable `DB\_PASSWORD` to your MySQL password.

5\. Deploy the project in Tomcat.

6\. Open `http://localhost:8080/LocalBusinessDirectory/`
