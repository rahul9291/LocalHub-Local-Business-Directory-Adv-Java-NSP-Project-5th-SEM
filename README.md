
# LocalHub – Local Business Directory Portal

LocalHub is a web-based application that helps users discover local businesses. Business owners can register and list their businesses, while administrators can approve or reject business listings.

## Features

- User registration and login
- Browse and search local businesses
- Category-wise business filtering
- Business owner dashboard
- Add, edit and delete business listings
- Admin dashboard
- Approve or reject business listings
- Role-based access control

## Technologies Used

- HTML
- CSS
- Java
- Java Servlets
- JDBC
- MySQL
- Apache Tomcat

## Database

Database Name: `local_business_directory`

Tables:
- users
- categories
- businesses

## Project Setup

1. Install JDK, Apache Tomcat and MySQL.
2. Create the database `local_business_directory`.
3. Create the required database tables.
4. Set the environment variable `DB_PASSWORD` to your MySQL password.
5. Deploy the project in Apache Tomcat.
6. Open the following URL in your browser:

`http://localhost:8080/LocalBusinessDirectory/`
